## Title

Tri-Signal: GenLayer Spinner

## Notes / Description

Tri-Signal is a production-ready GenLayer loading spinner where three transparency cuts travel inward through the assembled GenLayer mark from the lower-left tip, lower-right tip and upper split. Each signal has its own timing window, and only after the third reaches the center does the core give a brief confirmation pulse. The logo never rotates or breaks apart. The package includes the original zero-dependency animated SVG, reusable CSS, an optional React/TypeScript component, reduced-motion handling, light and dark demos, 16 to 64px scale checks, and a live loading-state page that uses the exact repository SVG.
